# MVP Scope

## Included

- Email and phone registration
- English and Spanish
- User profile
- Queue discovery
- Queue creation (admin/partner-curated and user-submitted-pending-approval
  — see `docs/decisions/005-hybrid-queue-authorship.md`)
- Presence registration
- GPS verification
- Photo evidence
- Basic community validation
- Auction creation
- Real-time bidding
- Test-mode payments
- Temporary QR transfer
- Ratings
- Basic disputes
- Administration
- Audit events

## Excluded

- Native mobile apps
- AI-based queue-position detection
- Facial recognition
- Cryptocurrency
- Subscription plans
- Advertising
- Automatic worldwide launch
- Disney or large-brand integrations
- Complex rewards
